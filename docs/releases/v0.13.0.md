# OrgForge 0.13.0

OrgForge now adapts its teams and execution to project work, learns from reviewed
results, and validates products through customer journeys and independent board
assessments.

- Dynamic teams and persistent company memory with searchable evidence.
- Reviewed model and strategy routing, estimated cost per success, and bounded
  autonomous work that preserves human approval gates.
- Optional role-scoped MCP tools and native Chromium execution.
- Persistent scheduled employees, incident triage, benchmark competitions,
  security scans, and executable red-team checks.
- Model-planned customer personas verified in a real browser and independent
  eight-dimension board reviews with CEO decisions.
- Checksum-pinned local agent/skill packages and signed, scoped federation
  proposals and results.
- Operations dashboard and nonroot Docker hosting with persistent storage,
  backups, health checks, and Caddy HTTPS configuration.

Existing companies receive additive database migrations. New automation and
external integrations remain opt-in. Back up company data before upgrading.
Federation exchanges reviewed messages; the marketplace is a local catalog.
Public hosting requires a server, DNS, and runtime credentials. Live provider
performance and external OSV access have not been validated.

Validation includes 199 offline tests, real Chromium/MCP workflows, Docker
startup, authenticated project creation, restart persistence, SQLite backup,
and Caddy configuration validation.

See the Phase 1, Phase 2, Phase 3, and deployment guides in `docs/` for setup and
the scope of each capability.
