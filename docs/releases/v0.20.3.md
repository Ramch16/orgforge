# Vittics Builder 0.20.3 — desktop buttons work

This release fixes desktop buttons that did not respond, including switching the team to Codex. Provider changes, worker pairing, tool installation, budget edits, agent replacement and key/node removal now use in-app dialogs. Cancel or press Escape to dismiss them.

Empty sign-in, build, message and key submissions show validation. Interrupted idea assessments preserve completed consultations; review feedback still requests fresh input.

## Install

- **macOS (Apple Silicon):** Quit Vittics Builder, open the DMG, and drag the app into Applications. Choose Replace if prompted. Launch the copy in Applications. If macOS cannot verify it, use System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** Quit Vittics Builder and run the setup installer.

Existing company data is kept. This version is numbered 0.20.3 so it is distinguishable from the previous 0.20.2 build.

The source tests passed on macOS, Windows and Linux, and the dialog regression test passed in Chromium CI. Installer builds smoke-test the bundled backend; macOS also verifies the app signature both before and after DMG packaging.
