# Vittics Builder 0.19.0

OrgForge is now **Vittics Builder**. Nothing about how it works has changed: same company, same
agents, same dashboard, under the new name.

| | Before | Now |
|---|---|---|
| Command | `orgforge` | `vittics-builder` |
| Python package | `orgforge` | `vittics_builder` |
| Settings | `ORGFORGE_*` | `VITTICS_*` |
| A company's data folder | `.orgforge/` | `.vittics/` |
| Desktop app | OrgForge, `~/OrgForge` | Vittics Builder, `~/VitticsBuilder` |
| Repository | Ramch16/orgforge | Ramch16/vittics-builder (the old address redirects) |

Upgrading carries everything over, for this release:

- The `orgforge` command still runs, with a note to use `vittics-builder`; it will be removed later.
- `ORGFORGE_*` environment variables still work when the `VITTICS_*` one is not set.
- A company's `.orgforge/` folder is renamed to `.vittics/` the first time it is opened. A paired
  worker machine's configuration moves from `~/.orgforge/` to `~/.vittics/`.
- The desktop app keeps using an existing `~/OrgForge` folder. Sign in again once if asked.
- Hosted servers keep their data in the same `company` volume, now mounted at
  `/var/lib/vittics-builder`; projects are found again at the new path automatically.
- Also new: a company that is moved to another folder finds its projects' workspaces again.

To upgrade an install from source: `pip uninstall orgforge`, then `pip install -e .` in the
updated repository. Update your git remote with
`git remote set-url origin https://github.com/Ramch16/vittics-builder.git` (GitHub redirects
the old one meanwhile).

The installers attached to this release are not signed: Windows SmartScreen and macOS Gatekeeper
warn on first open (Windows: More info, then Run anyway; macOS: Control-click the app, then Open).
The Windows app has been built and its backend smoke-tested in CI, but not yet opened on a real
Windows PC. The desktop app's identifier changed, so macOS and Windows treat it as a new app; remove
the old OrgForge app yourself.

Validation includes 270 offline tests on Linux (Python 3.11 and 3.12), macOS and Windows, migration
tests for old companies, settings, worker configs and moved folders, and the renamed desktop app
built, opened and quit on macOS, with its backend smoke-tested on Windows and macOS.
